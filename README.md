# E-Commerce Backend

This project was built while learning backend development using Java and Spring Boot. The main goal was to understand how backend systems work, including APIs, MVC architecture, controllers, endpoints, payload handling, and database interaction.

It was my first proper backend-focused project and helped me understand how applications store, retrieve, and update data in real systems.

## Tech Stack

- Java
- Spring Boot
- PostgreSQL
- Postman

## What I Learned

- MVC architecture
- REST API fundamentals
- Controllers and endpoints
- Request/response handling
- Database integration using PostgreSQL
- Basic backend system design concepts
